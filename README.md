# Personal AI Skills

Codex와 Claude Code에서 사용하는 재사용 가능한 AI 스킬 모음입니다.

각 스킬은 반복 작업을 일관된 절차와 품질 기준으로 수행하도록 돕는 지침입니다. 학습 자료 제작, 문서 정리 등 실제 사용 목적에 맞춰 직접 만들고 개선합니다.

## Skills

| Skill | 목적 |
|---|---|
| `course-study-skill` | 강의 자료를 바탕으로 출처와 검증이 포함된 시험 대비 학습 자료 제작 |

각 스킬의 상세한 사용 조건과 절차는 해당 스킬 폴더의 `SKILL.md`를 참고하세요.

## 사용

사용하는 AI 도구의 스킬 폴더에 원하는 스킬을 설치하거나 복사한 뒤, 해당 작업을 요청하면 됩니다. 입력 자료와 결과 형식은 각 스킬의 안내를 따릅니다.

## 원칙

- 실제 반복 작업에 필요한 지침을 기록합니다.
- 출처와 검증 여부를 분명히 합니다.
- 사용 결과를 바탕으로 지침을 계속 개선합니다.
